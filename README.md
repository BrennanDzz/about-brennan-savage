## English

A website about Brennan Savage, created as a front-end development practice project. It explores his musical style, background, and career through a multi-page website with a responsive design.

### Live Demo

[Visit the website](https://brennandzz.github.io/about-brennan-savage/index.html)

### About the Project

The goal of this project is to practise front-end development by building a multi-page website using HTML, CSS, and JavaScript.

The website focuses on a clean visual design, accessible navigation, and a responsive layout that adapts to different screen sizes.

### Pages

* **Home:** An introduction to Brennan Savage.
* **Style:** Information about his musical style.
* **Education:** His background and early influences.
* **Career:** An overview of his musical career and selected tracks.

### Technologies Used

* **HTML5** — Website structure and content.
* **CSS3** — Styling, layouts, and responsive design.
* **JavaScript** — Interactive functionality.

### Project Structure

```text
about-brennan-savage/
├── Css/
├── Img/
├── Js/
├── index.html
├── estilo.html
├── formacion.html
└── trayectoria.html
```

### Responsive Design

The website is designed to adapt to desktop, tablet, and mobile screens using CSS media queries and responsive layouts.

### What I Learned

* Structuring a multi-page website with HTML.
* Creating layouts with CSS Grid and Flexbox.
* Implementing responsive designs with media queries.
* Organising stylesheets and image assets.
* Using Git and GitHub to manage and publish a project.

## Español

Una página web sobre Brennan Savage, creada como proyecto de práctica de desarrollo frontend. Explora su estilo musical, sus antecedentes y su trayectoria a través de una web de varias páginas con diseño adaptable.

### Demo

[Visitar la página web](https://brennandzz.github.io/about-brennan-savage/index.html)

### Sobre el proyecto

El objetivo de este proyecto es practicar el desarrollo frontend mediante la creación de una página web con varias secciones, utilizando HTML, CSS y JavaScript.

La web apuesta por un diseño visual limpio, una navegación sencilla y una estructura adaptable a diferentes tamaños de pantalla.

### Páginas

* **Inicio:** Presentación de Brennan Savage.
* **Estilo:** Información sobre su estilo musical.
* **Formación:** Información sobre sus antecedentes e influencias iniciales.
* **Trayectoria:** Recorrido por su carrera musical y una selección de canciones.

### Tecnologías utilizadas

* **HTML5** — Estructura y contenido de la web.
* **CSS3** — Estilos, distribución de elementos y diseño responsive.
* **JavaScript** — Funcionalidades interactivas.

### Estructura del proyecto

```text
about-brennan-savage/
├── Css/
├── Img/
├── Js/
├── index.html
```

### Diseño responsive

La web se adapta a ordenadores, tabletas y móviles mediante media queries de CSS y diseños flexibles.

### Aprendizajes

* Organizar hojas de estilo y recursos gráficos.
